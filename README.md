# One Sentence for a Traveler from 1800

A single original sentence that explains the modern internet to someone
arriving from the year 1800, built only from things such a traveler already
knows — roads, libraries, post offices, letters, ink — so the picture lands
at once: one invisible road joining every library, post office, and fireside
chat on earth, carrying a letter from London to China before its ink dries.

Running `main.py` writes the sentence to the path in `OUTPUT_PATH`
(default `/output/entry.txt`).
